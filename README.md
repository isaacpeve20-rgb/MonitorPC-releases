# MonitorPC

Monitoriza cada componente de tu PC (CPU, GPU, RAM, discos, red...) en tiempo real: temperatura,
estrés, histórico por día/semana/mes/año, informes y un asistente que te avisa si algo empieza a
ir mal.

Este repositorio aloja únicamente las **versiones publicadas** (instalador + fichero de
actualizaciones) — el código fuente vive en un repositorio privado.

## Descargar

La última versión siempre está en **[Releases →](../../releases/latest)**.

- Windows 10/11 (64 bits)
- Gratis, con una edición **[PRO](https://monitorpc.lemonsqueezy.com/checkout/buy/7defdde3-ea1b-4689-a228-c4f35b97155a)** opcional: histórico ilimitado, informes en PDF y PCcompy sin límite de preguntas.
- Todo funciona en local — sin telemetría.

## Actualizaciones

Una vez instalada, la app se actualiza sola comprobando este repositorio; no hace falta volver
a descargar nada a mano.
